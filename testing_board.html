Synthesis & Next Steps

Summary of Findings

What testing proved, and what to fix before build.

Validated ✓

What Worked Well

5 strengths
🟦
“Ask for Help” button
Visible, non-intimidating, impossible to miss, both users tapped it without hesitation.
🟨
“I don’t know how to ask”
Directly addresses the Week 4 insight, users said “that’s literally me”.
🏆
Help Hero badges
Reframes help-seeking as strength, creates genuine pride, not shame.
🟪
Anonymous Help Wall
Normalizes help-seeking, “I’m not alone” was repeated across sessions.
💬
Text-only community
Low-bandwidth is non-negotiable, validated as ~2 KB/post, phone-friendly.

What Needs Improvement

3 gaps
“I don’t know how to ask” should be more visible
Move it to the main screen, it’s the killer feature, don’t bury it.
Offline access is critical
Add download for Help Wall, users need answers with no internet.
Show “how many others asked this”
Add “Similar questions” / “Popular now” to speed up finding answers.

Iteration Plan

Prioritized changes directly from testing feedback.

011
Move “I don’t know how to ask” to the main screen
Users identified with this instantly, it should be immediately visible
High priority
022
Add offline download for Help Wall
Users need access to Q&A even without internet, cache + sync
Must have
033
Add “Similar questions” feature
Helps users find answers to what they’re struggling with, reduce duplicate asks
044
Add “Help Hero of the Month”
Gamification to encourage more help-seeking, social proof + motivation
055
Add dark mode
Allows study at night without disturbing family on shared device
Nice to have

Key Learnings

  • The “Help Heroes” concept resonates deeplywith first-generation students
  • “I don’t know how to ask” is the killer feature, highest emotional resonance
  • Help Hero badges create genuine pride, shame to strength reframing works
  • Community is essential, normalizes help-seeking, reduces isolation
  • Low-bandwidth design is non-negotiable, access > aesthetics
